CURSO DE REGLAS BÁSICAS DE DERIVADAS - ARCHIVOS LISTOS PARA GITHUB PAGES

Contenido de esta carpeta:

1. index.html
   Página principal del curso.

2. styles.css
   Archivo de estilos visuales de la página.

3. assets/formulas-basicas-derivadas.png
   Imagen de apoyo con el formulario de reglas básicas.

4. .nojekyll
   Archivo vacío para evitar que GitHub Pages procese el sitio con Jekyll.

IMPORTANTE:
No subas el archivo ZIP directamente a GitHub pensando que se publicará solo.
Primero descomprime el ZIP y sube el contenido de la carpeta:

- index.html
- styles.css
- carpeta assets
- .nojekyll
- README-INSTRUCCIONES.txt (opcional)

PASOS PARA PUBLICAR EN GITHUB PAGES

1. Entra a GitHub.
2. Crea un repositorio nuevo.
   Nombre recomendado: curso-derivadas
3. Selecciona visibilidad Public.
4. Sube los archivos de esta carpeta al repositorio.
   Asegúrate de que index.html quede en la raíz del repositorio, no dentro de otra carpeta.
5. Entra al repositorio.
6. Ve a Settings.
7. Ve a Pages.
8. En Source o Build and deployment, selecciona:
   - Deploy from a branch
   - Branch: main
   - Folder: /root
9. Presiona Save.
10. Espera unos minutos. GitHub generará un enlace parecido a:
    https://tuusuario.github.io/curso-derivadas/

RECOMENDACIÓN:
Después de publicar, abre el enlace desde una ventana incógnita o desde tu teléfono para confirmar que la página sea pública.

SI LOS VIDEOS NO APARECEN:
- Verifica que el video en YouTube no esté privado.
- Puede estar público u oculto, pero no privado.
- Si está oculto, las personas con el enlace o la página podrán verlo.
